# Imago v0.1.4 consumer upgrade — 21 November 2026

## Revisions and scope

Muro base: `af8f52388fe882282a8f4d1618ccc112ff082fcf`.
Imago moves from `v0.1.3` (`81da040065bd502013adbd1b0dd8a40cfcf11a7d`)
to released `v0.1.4` (`1c5ffa2005a613eeb64a63dbebb528ad93b4c608`).
Both npm and Rust manifests pin the tag; both lockfiles pin that same immutable commit.

Imago [PR #5](https://github.com/acaprino/imago/pull/5) was merged after its
Verify checks passed. Its [release run](https://github.com/acaprino/imago/actions/runs/44893962198)
completed successfully before these consumer references were changed.

## Compatibility review

- Added persistent tiling/file workspaces, editable graphs, keyed DOM lists and
  navigation/content surfaces. They are available without forcing new product
  behaviour into Muro.
- Muro's `graphView` implementation and scene contract are unchanged; the new
  editor is an additional export.
- Menu signatures remain compatible; layer callbacks and sheet/picker options
  are additive. Existing browser coverage exercises focus, dismissal, menu-to-dialog
  transitions, modal blocking, retries and teardown.
- `mountZoom` retains Muro's storage key, default 50–200% range, 10% increments,
  keyboard/wheel handling and cleanup. Its new controller tracks concurrent native
  replies; consumer regressions cover late successes and overlapping refusals.
- The default `.im-stack` gap is smaller. Muro uses it for the capability Entry
  values; the existing grid layout remains applicable.
- No Rust API or runtime dependency changes. The crate now carries its workspace
  license. Existing dependency versions, registry checksums and transitive lock
  entries are preserved; only Imago version/tag/commit values change.

## Verification

Local preparation used the exact Imago source revision `5ab114c9e2009acce77d981df40a249db932d5d4`,
subsequently released by the workflow with version metadata updates.

- 343 existing targeted Muro frontend tests plus the first two consumer zoom
  tests passed (345 total).
- Four upstream zoom-controller tests passed.
- Muro TypeScript compatibility passed. Imago compatibility also passed using
  cached TypeScript 5.9.3, temporary D3/Vite declarations and a temporary DOM
  `HTMLElement.moveBefore` declaration. These are outside product source.
- The zoom tests were subsequently strengthened during review: late successful
  replies, two overlapping refusals and capture-aware listener removal. This
  final revision is checked by GitHub Actions, not claimed as rerun locally.
- The local host disconnected after preparation. Final manifest/lock edits and
  strengthened tests were prepared against GitHub's immutable Muro base.

The required release gate is Muro's Tests workflow on the final commit: actual
`npm ci`, the pinned TypeScript/Vite build, all frontend tests, browser tests,
the full Python suite and Rust/shell tests with `--locked`.
Rust is never compiled locally. Interactive Windows caption, tray and WebView
recovery behaviour is not claimed as manually verified.
