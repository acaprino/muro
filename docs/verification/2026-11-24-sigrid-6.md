# Sigrid 6.0.0 (2026-11-24)

The desktop moves from Sigrid 5.0.0 to **6.0.0** (ADR-0031). Sigrid 5.0.0 changed the graph canvas (a line carries its look as custom
properties, no class) and 6.0.0 moved what draws out of the main entry; the `Tests` run on `86b9a4a` had two browser tests of the graph red
for the first reason (`browser-workspace.mjs`).

The tarball and the manifest were downloaded with `gh release download` into an empty folder, hashed and unpacked with `tar` there; nothing of
it was installed or run. Peer dependencies: `react ^19`, `react-dom ^19`, `@tauri-apps/api ^2` (Muro is on React 19.3.1). The lockfile was made by
the throwaway `Lockfile` workflow (`npm install --package-lock-only --ignore-scripts`, run 45451753860) and taken with `gh run download`; the workflow
lived on a short branch and is not in this commit.

## What changed

1. `package.json` and `package-lock.json`: Sigrid 6.0.0.
2. 28 files of `apps/desktop/src`: the imports. "From 5.x to 6" of Sigrid's README: what draws is imported from the entry of its level
   (`/primitives`, `/components`, `/layout`, `/assemblies`) and `@acaprino/sigrid` keeps what does not draw. 51 names moved, none removed or renamed.
   `Dialog` is the `/components` one (`/primitives` exports its parts, `DialogRoot` among them); `Icon` and `IconName` are `/primitives`.
   A script read the d.ts of each entry of the unpacked release and rewrote the lists.
3. `apps/desktop/tests/browser-workspace.mjs`: `drawnLines` reads the four properties on the path of a line (`--sigrid-line-dash`, `-stroke`, `-width`)
   with Sigrid's own values (`LINE_STYLES`, `LINE_TONES`, `LINE_NEAR`, `LINE_PATH` of `src/assemblies/graph-lines.ts`). The path has no mark of its own in the
   DOM: it is the accent at 2px, which the test says. Nothing was asked of Sigrid for it.

## Not run

Nothing was compiled, type-checked or run on this machine (AGENTS.md): the imports, the types and the browser tests wait for the `Tests` run. The
selectors of `drawnLines` are written from the source of Sigrid, not seen in a browser. `npx --no sigrid-check apps/desktop/src` waits for the same run.
