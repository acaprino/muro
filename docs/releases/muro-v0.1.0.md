# Muro 0.1.0

First tagged release of the factory.

- Delivery forms (`delivery.json`): each part of a source becomes a capability, permanent policy, a hook, or is dropped, with a recorded reason; a release registers what its package declares.
- The substance of a source is never altered (ADR-0017): entry prompts, selection descriptions and hook text are generated by the host LLM, and an activated capability refers to the packaged original for what the task needs.
- `intake_only_paths`: selected files the generated plugin does not need do not travel.
- No limit of the factory's own on data leaving the machine.
- Native adapters for Claude Code, Codex, OpenCode, Pi and Hermes; on Hermes a policy over 4,000 characters goes whole through `pre_llm_call`.
- Routing eval, discovery entries and conditional prerequisites (ADR-0012 to ADR-0015).

Verification: `python -m pytest -q` 471 passed, 15 skipped.
Not executed: a live Hermes session; host sessions on the final tree.
