# Marionette 0.5.1

Revising an active request now reruns its steps by default. The host can explicitly keep a reviewed, completed step when its intent, inputs and prerequisites still apply to the revised request. An invalid amendment leaves the active map available for the next turn.

- When a prerequisite runs more than once, the decision must identify the intended occurrence. A reference to a missing occurrence is rejected.
- Literature-source choices apply to delegated research. Office, CSS and design checks account for work that does not apply to the requested deliverable. A directly generated PDF still requires visual verification of the delivered PDF.
- The Wayfinder capability now opens its pinned methods for clarification, domain modeling, prototyping and implementation, including their supporting files.

The routing benchmark contains 94 cases. The recorded blinded classification passed all 94, and the ten runtime probes from the original review passed on replay. The benchmark evaluates routing decisions. End-to-end host execution and the usefulness of a clarification question require separate checks.

Install the adapter for your host from the release archive to use the updated runtime and catalog.
