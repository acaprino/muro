## Delivery form correction

Requirement REQ-015 was added by hand on 2026-11-12 from
[ADR-0016](../adr/ADR-0016-delivery-form-and-self-registering-releases.md): every
intake records what each part of a source becomes, and a release registers what
that record declares. It replaces the "passive hooks" wording of the note above
and of ADR-0003. The generated index below still shows the first extraction.

The native-policy correction updates FRD-0001 to **Proposed v4, 18 requirements**:
policy-only packages, explicit system/developer channels for the five hosts,
delivery-bound decisions and evals, and literal hook arguments with Codex context
envelopes. The generator is not available in this checkout, so this note states
the current record without rewriting the historical generated block.

Three requirements were added by hand later on 2026-11-12, without a version
change: REQ-019 (a transformed original is not shipped, `intake_only_paths`),
REQ-020 (each adapter installs with its host's own command) and REQ-021
(absorbed content is carried in the source's own words and changes only for
harmonization and coexistence, from
[ADR-0017](../adr/ADR-0017-absorbed-content-is-not-altered.md)). REQ-015 now
states the always-on limit as 6000 characters for each contributing source.

REQ-021 was reworded by hand the same day after the owner's correction ("hai
preso troppo alla lettera"): the text that selects and starts a part is
generated by the host LLM, the substance is the source's, and an activated
capability refers to the packaged original only for what the task needs.

Two requirements were added by hand on 2026-11-13, without a version change,
after a live session the owner judged "errori gravissimi": REQ-022 (evidence
describes the step it is bound to: `intent_checks`, `check_conditions`, the
`not-applicable` status and the runtime's rejection of a check on the wrong step,
from [ADR-0018](../adr/ADR-0018-checks-scoped-to-the-step-intent.md)) and REQ-023
(a package names the originals it absorbs where the host chooses a skill:
`absorbs` in `entries.json`, from
[ADR-0019](../adr/ADR-0019-absorbed-originals-named-at-discovery.md)). REQ-006,
REQ-010, REQ-011 and REQ-013 were extended to match. FRD-0001 now holds 23
requirements.
