# Harness logo sources

These assets match the harness marks used by [Mukade](https://github.com/acaprino/mukade).

| Harness | Source |
| --- | --- |
| Claude Code | [Lobe Icons](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/claudecode-color.svg) |
| Codex | [Lobe Icons](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/codex-color.svg) |
| OpenCode | Mark from the [OpenCode brand assets](https://opencode.ai/brand), with light and dark variants taken from the [wordmarks in Distilly](https://github.com/titanwings/distilly/tree/dot-skill/docs/assets/hosts) |
| Pi | [Pi press kit](https://pi.dev/press-kit), via the [badge in Orchestrator](https://github.com/backnotprop/orchestrator/blob/main/assets/providers/pi-badge.svg) |
| Hermes Agent | [Hermes Agent favicon](https://github.com/NousResearch/hermes-agent/blob/main/website/static/img/favicon.ico), exported as PNG |

The marks identify the supported harnesses and belong to their respective owners. The Claude Code and Codex SVGs are distributed with the [Lobe Icons MIT notice](LICENSE-lobe-icons).
